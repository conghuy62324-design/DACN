## Recovery rules

Known precommit rollback: evidence first, baseline verify in newly authorized bounded scope; no blind connection retry. Ambiguous COMMIT: retain intent/ledger/volume, stop inference, reconcile actual transaction state with new identity/admission proof before deciding exact cleanup. Committed fixtures: original ticket may authorize cleanup only if all guards still valid; crash recovery is not automatically granted a new writer session.

Security breach: quarantine while denying admission remains configured; do not grant admin/HBA relaxation or terminate unknowns automatically. No claim of safe continuous I once breach evidenced. Cleanup/final failure: keep records and isolated volume for review, never change expected or overwrite baseline. Backup/recreate applies only approved disposable resources and new acceptance epoch; historical reports/old database never restored or changed by this plan.
