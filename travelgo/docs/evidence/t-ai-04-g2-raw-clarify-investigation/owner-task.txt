## 3. So sánh L01, L02, L03, L04

Phân tích bốn lượt trên cùng session:

L01:
- Chọn ô tô.
- Model trả đúng plan_trip.

L02:
- Đổi ngân sách.
- Model giữ các slot khác và trả đúng plan_trip.

L03:
- Đã hủy ô tô ở D05.
- Chọn xe máy.
- Server xác minh transportation=motorbike.
- Model lại hỏi transportation.

L04:
- Đổi điểm đến.
- Model giữ đúng transportation=motorbike và trả plan_trip.

So sánh cụ thể:

- Current message wording.
- Server verified values.
- Role và message order.
- Instruction precedence.
- Required-field presence.
- Token budget.
- JSON schema.
- Model output length và completion.
- Các điều kiện khiến model chọn clarify.

Không mặc định nguyên nhân nằm ở prompt chỉ vì model trả clarify.

## 4. Phân tích các giả thuyết

Kiểm tra bằng source và evidence:

A. G2 SYSTEM supplement có instruction chưa rõ về việc sử dụng SERVER_VERIFIED_SLOTS hay không?

B. Có mâu thuẫn giữa instruction của G1 về current user message và instruction mới của G2 về verified history không?

C. Structured verified slots được đặt ở vai trò/thứ tự có khiến model coi transportation là dữ liệu chưa xác nhận không?

D. Sau D05 unset rồi L03 SET motorbike, có metadata hoặc biểu diễn trạng thái nào khiến model hiểu sai thành transportation vẫn thiếu không?

E. L03 có khác biệt wording hoặc request construction so với L01/L02/L04 không?

F. Original tool schema/decision prompt có thể khuyến khích clarify quá mức trong tình huống correction không?

G. Provider JSON mode, truncation, deadline hoặc parse path có bất thường nào trong L03 không?

H. Có bằng chứng về vấn đề runtime GPU ảnh hưởng riêng semantic L03 không?

Phân biệt rõ mức độ:

- CONFIRMED: chứng minh bằng source/evidence.
- LIKELY: có bằng chứng ủng hộ nhưng chưa xác nhận nguyên nhân.
- HYPOTHESIS: mới là khả năng.
- RULED_OUT: có bằng chứng loại trừ.

Không gán nguyên nhân sâu khi chưa đủ bằng chứng.

## 6. Review budget grammar limitations

Báo cáo LIVE cũng ghi nhận hai false negatives:

- Natural decimal budget correction.
- Labeled numeric budget với trailing punctuation.

Đọc source và evidence gốc, xác nhận chúng có liên quan trực tiếp đến L03 hay không.

Nếu không liên quan, ghi là observation độc lập.

Không sửa parser hoặc mở rộng grammar trong investigation.

Không sử dụng lỗi khác làm lời giải thích cho L03 nếu thiếu bằng chứng.
