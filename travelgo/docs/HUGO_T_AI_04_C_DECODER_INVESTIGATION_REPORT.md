# T-AI-04-C — Điều tra đối chứng `format` của Ollama

Ngày 09/11/2026 (Asia/Ho_Chi_Minh). **Đã chạy đúng 8/8 inference local được phê duyệt, không retry: 4 PASS / 4 FAIL / 0 NOT RUN.** Trong bốn cặp input mới, Variant A (`format: DECISION_SCHEMA`, như production) trả `unsupported` **4/4**. Variant B (`format: "json"`) trả đúng `search_places` và `plan_trip`, trả `unsupported` đúng ở intent ngoài phạm vi, nhưng D03-B tạo `clarify` không hợp lệ. Evidence **ủng hộ** giả thuyết lựa chọn `format`/structured decoding ảnh hưởng decision selection; chưa chứng minh đây là nguyên nhân duy nhất hay JSON mode đủ an toàn để đưa vào production. **TAI03B-B1-01 (P1) vẫn OPEN.** Không sửa production hoặc chạy benchmark V2.

## 1. Baseline, giả thuyết và phân tích offline

[Benchmark V2 trước FIX](HUGO_T_AI_03_B_LIVE_V2_B1_FINAL_REPORT.md) có **3/24 PASS**, parsed decision `unsupported` 24/24. [Probe sau FIX](HUGO_T_AI_04_B_LIVE_PROBE_REPORT.md) có **2/5 PASS**, cả năm raw/parsed response là `{"kind":"unsupported"}`. [FIX report](HUGO_T_AI_04_A_FIX_REPORT.md) và [root-cause offline](HUGO_T_AI_04_A_ROOT_CAUSE_OFFLINE_REPORT.md) xác nhận prompt sau FIX có routing tích cực và tool descriptions, nhưng root JSON Schema `anyOf` vẫn gồm bốn nhánh. Tác động nhân quả của prompt, model hay decoder trước task này chỉ là giả thuyết.

[Offline findings](evidence/t-ai-04-c-decoder-investigation/run-20261109T032541561Z-fa6de3a0/offline-findings.json) dựng từ source đang chạy: `DECISION_SCHEMA.anyOf` theo thứ tự `clarify`, `tool/plan_trip`, `tool/search_places`, `unsupported`; các object đều `additionalProperties:false`. Clarify bắt buộc `kind,fields`, hai tool bắt buộc `kind,name,arguments`, unsupported chỉ cần `kind`. `kind`/`name` có enum phân nhánh; `FIELD_LABELS` không chứa `children`. Prompt system có mô tả cả hai `AGENT_TOOLS`, required fields và bốn ví dụ JSON; user/history là message riêng thấp hơn system. Provider tạo body với `stream:false`, `temperature:0`, `num_ctx:16384`, `num_predict:2048`, timeout **15 giây**. Không tìm thấy nhánh server nào tự đổi parsed decision đúng thành unsupported; các baseline trước đã chụp decision trước fallback.

Giả thuyết **được thử đúng một biến**: `format` dạng schema object có thể làm model/decoder thiên về nhánh `unsupported` ngắn nhất. `unsupported` nằm cuối `anyOf`, nên dữ liệu không ủng hộ giả thuyết “luôn chọn nhánh đầu”. Một số yếu tố như model/template, prompt wording, quantization và thứ tự chạy A rồi B vẫn chưa được tách riêng bằng phép thử này.
